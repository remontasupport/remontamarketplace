# Targeted inventory: worker tools for Cleaning and Home & Yard Maintenance (2026-10-22, `main` `62e24f9`)

**Request (user, verbatim):** "I want to add a lists of a cleaning tools and yard and maintenance tools to the worker's
dashboard if their services have cleaning and yard and maintenance"

## The two services today

- The catalogue (`Category`, `packages/db/prisma/schema.prisma:339`) has `cleaning-services` "Cleaning Services" and
  `home-yard-maintenance` "Home and Yard Maintenance", both `requiresQualification = false`
  (`packages/db/scripts/local/seed-catalogue.sql:18-19`). **Neither has a subcategory.** (Support Worker's
  "Domestic tasks (cleaning, laundry, home organisation)" is a separate subcategory of `support-worker`.)
- A worker's choice is a `worker_services` row (`schema.prisma:391`): `categoryId`, `categoryName`, `subcategoryIds/Names`,
  and a **`metadata Json?`** column (corrected 2026-10-22: it holds the nursing/therapeutic registration, `writeServiceRegistration` in `apps/api/src/modules/worker/application/sections/services.ts`; unused for these two services). Written by `PUT /v1/worker/services` (`packages/api-contract/src/worker.contract.ts:394`);
  read back in the profile read `GET /v1/worker/profile` as `services[]` (`worker.contract.ts:287`).
- Documents: both services ask nothing required, one optional `qualification-certificate`
  (`apps/api/src/modules/worker/domain/service-requirements.ts:38-39`; app copy `apps/app/src/config/serviceDocumentRequirements.ts:89`);
  no qualifications (`apps/app/src/config/serviceQualificationRequirements.ts:133,145`).

## Where it would show on the dashboard

- The sidebar is one declaration, `apps/app/src/features/navigation/workerMenu.ts`: Dashboard, My Profile, **Services**
  (one setup step per chosen service, generated by `servicesChildren` from `serviceNamesOf(profile)`, then Service Area),
  Compliance, Additional Credentials, My Jobs, Account.
- Each service's step is `/dashboard/worker/services/setup?step=<slug>` rendering `ServiceQualificationStep`
  (`apps/app/src/config/servicesSetupSteps.ts`): for these two services it shows only the optional certificate upload.
- The dashboard home: `apps/app/src/app/dashboard/worker/(home)/page.tsx`. Completion (C1, `COMPLETION_MODEL=legacy`)
  has a `services` group (`worker.contract.ts:315`).

## Constraints that apply

- "Dynamic by default": a new write is a contract entry + a handler; any form goes through the form engine or the
